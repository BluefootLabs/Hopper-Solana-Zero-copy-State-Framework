# Archive

This folder keeps historical research, presplit audits, and older systems-mode
design notes out of the beginner documentation path.

These files can still be useful for archaeology, safety review, or design
background, but they may include outdated first-touch syntax such as
`#[hopper::context]`, raw `AccountView` examples, or manual entrypoints. New
programs should start with [../FIRST_FIVE_MINUTES.md](../FIRST_FIVE_MINUTES.md)
or [../GETTING_STARTED_SERIOUS.md](../GETTING_STARTED_SERIOUS.md).

# hopper-svm

Hopper-owned host execution harness for Hopper programs.

This crate fabricates aligned Hopper Native account buffers and invokes the
host-callable dispatcher generated by `#[hopper::program]`. It is intended for
fast framework tests that need real Hopper account views and host-emulated
System Program calls (transfer, create account, allocate, assign) without
pulling an external SVM harness.

```rust,ignore
use hopper_svm::{AccountFixture, HopperSvm};

let result = HopperSvm::new().process_instruction(
    program_id,
    &instruction_data,
    &[AccountFixture::new(user, owner, 1_000_000_000, 0).signer().writable()],
    // Generated by `#[hopper::program] mod vault_program { ... }`.
    __hopper_process_instruction_vault_program,
);
assert!(result.program_result.is_ok());
```

`ProcessResult` returns the program result and the post-execution account
fixtures. It does not meter compute: `compute_units_consumed` is always `0`,
so use an SBF runtime for CU measurements.

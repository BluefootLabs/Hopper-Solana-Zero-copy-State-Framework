# Unsafe map

Generated by `scripts/audit-map.py` from the source tree. Do not edit by
hand: run the script, and the gate (`--verify`) fails when this file and
`unsafe-map.json` no longer match the code.

Every `unsafe` block, function, impl, and trait outside test code is a
site. A site is named `path::function#n`, so it keeps its name when the
lines around it move. `unsafe-map.json` holds the full record of each
one, with a SHA-256 of its code.

"Reached through" follows calls by name inside the audited sources,
starting from the functions the tests call. It is a text match, so it
over-counts a little where two functions share a name and under-counts
calls made through a trait or a macro.

Reading the numbers: "boilerplate" means the site carries the sentence
"part of Hopper's reviewed zero-copy/backend boundary", which says a
person looked and does not say why the code is sound. Those sites are
where a reviewer's time goes first. "Called by name" is a text match on
the enclosing function's name. It finds direct calls. It does not see a
test that reaches the function through a safe wrapper, and it skips
names too common to attribute (`new`, `get`, `load`).

## Review ledger

`audit/unsafe-review.json` records a reviewer's sign-off per site with
the hash of the code that was read:

```text
python scripts/audit-map.py --sign <id> --reviewer <name> --note <text>
python scripts/audit-map.py --check
```

`--check` lists every site that was signed and has changed since, every
signed site that no longer exists, and how many sites have no sign-off.
It exits 2 when a signed site changed, so a release cannot carry a
sign-off for code nobody re-read.
